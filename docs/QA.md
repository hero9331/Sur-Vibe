# 전체 점검표 (배포 후, ~12/1)

배포한 주소에서 **폰과 노트북으로 각각** 처음부터 끝까지 해 봐요. 안 되는 건 GitHub Issues에 **버그 신고** 양식으로 올려요.

버그 신고는 오류 화면 캡처와 콘솔 메시지를 AI에게 주고 재현 순서, 기대 결과, 실제 결과로 정리시킨 뒤 올리면 빨라요.

진짜 결제내역은 쓰지 않아요. `eval/samples/`의 가짜 캡처나, 이름과 번호를 가린 캡처를 써요.

## 1. 정상 흐름

- [ ] 새 아이디로 가입하면 홈으로 간다
- [ ] 설정에서 계좌 2개, 월 예산, 고정비를 저장하고 새로고침해도 남아 있다
- [ ] 캡처 1장을 올리면 날짜, 가게, 금액, 카테고리가 나온다
- [ ] 금액과 카테고리를 고치고 더치페이 2명을 넣으면 내 몫이 절반이 된다
- [ ] 저장하면 내역 화면에 보인다
- [ ] 내역에서 카테고리를 고친 가게는 다음 캡처에서 **기억한 분류**로 나온다
- [ ] 홈의 오늘 쓸 수 있는 돈을 손으로 계산한 값과 같다
- [ ] 80%를 넘으면 노란색, 100%를 넘으면 빨간색이다
- [ ] 월별 그래프 합계가 내역 합계와 같다
- [ ] 지난달보다 늘어난 건 빨간색, 줄어든 건 초록색이다
- [ ] 많이 쓴 카테고리에 맞는 정책이 나오고 링크가 열린다
- [ ] 로그아웃하면 다시 로그인해야 들어갈 수 있다

## 2. 돈 계산

- [ ] 내 계좌로 보낸 돈은 지출에 안 들어간다
- [ ] 친구에게 보낸 돈은 지출에 들어간다
- [ ] 받은 돈은 지출에 안 들어간다
- [ ] 고정비로 등록한 넷플릭스 결제가 두 번 빠지지 않는다
- [ ] 같은 캡처를 또 올리면 "이미 저장한 내역 같아요"가 뜬다

## 3. 일부러 틀리게

- [ ] 사진이 아닌 파일의 확장자를 `.png`로 바꿔 올리면 오류 메시지가 나온다
- [ ] 캡처 6장을 고르면 5장까지만 된다
- [ ] 금액에 음수나 0을 넣으면 저장되지 않는다
- [ ] 계좌 이름 없이 추가하면 오류 메시지가 나온다
- [ ] 거래가 하나도 없는 새 아이디로 모든 화면이 오류 없이 열린다
- [ ] 없는 주소로 가면 안내 페이지가 나온다

## 4. 다른 사람 데이터

- [ ] 아이디 2개를 만들어 서로의 계좌, 내역, 설정이 안 보인다
- [ ] 다른 아이디의 거래 id로 `PATCH`, `DELETE`를 보내면 404다 (Thunder Client)
- [ ] 로그인 없이 API를 부르면 401이다

## 5. 화면 품질

- [ ] 모든 화면에서 콘솔 오류가 0개다
- [ ] Lighthouse가 모든 항목 90점 이상이다
- [ ] 폰에서 글자가 잘리거나 가로로 밀리지 않는다
- [ ] 영수증 디자인에서 벗어난 화면이 없다

## 6. 코드

- [ ] `npm test`에서 건너뛰는 시험 없이 실패 0개
- [ ] `npm run lint` 경고 0개
- [ ] `npm audit` 높은 위험 0개
- [ ] GitHub에 `.env`, 키, 진짜 캡처가 없다
