# 회고 (KPT)

일을 하나 끝낼 때마다 팀이 같이 돌아봐요. (10강 Retrospective)

## 언제

| 날짜 | 돌아볼 것 |
|---|---|
| 11/24 배포 직후 | 기능 만들기와 합치기 |
| 12/9 발표 직후 | 프로젝트 전체 |

## 하는 법 (20분)

1. 각자 3분 동안 메모를 써요. **K**eep(계속할 것), **P**roblem(문제였던 것), **T**ry(다음에 해 볼 것)을 하나 이상씩.
2. 메모를 모아 AI에게 정리시켜요.
3. Try 중 하나를 골라 담당과 날짜를 정해요.

```
[Role] 너는 팀 회고를 정리하는 진행자야.
[Context] 아래는 팀원 5명이 쓴 회고 메모야. 이름은 빼고 내용만 봐.
[Task] Keep, Problem, Try로 나누고, 비슷한 내용은 하나로 합쳐 줘.
       Try는 바로 할 수 있는 행동으로 바꿔 줘.
[Format] 세 칸짜리 표. 칸마다 3~5줄.
(메모 붙여 넣기)
```

## 기록 양식

| Keep | Problem | Try |
|---|---|---|
| | | |

**이번에 할 Try:** (담당, 날짜)

회고 내용은 노션 회의록에도 남겨요. 발표의 "배운 점"이 여기서 나와요.
