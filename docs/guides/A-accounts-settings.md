## 확인하는 법
1. `npm run dev` 실행, 브라우저에서 가입·로그인
2. **Thunder Client**(9강)로 API 확인
   - 로그인 API로 받은 토큰을 Headers에 `Authorization: Bearer 토큰` 으로 넣기
   - `POST http://localhost:3000/api/accounts` Body(JSON): `{"name":"생활비 통장","type":"bank","institution":"토스뱅크"}` → **201**
   - `GET /api/accounts` → 방금 만든 계좌가 보이면 성공
3. 설정 화면에서 직접 추가·삭제해 보기
4. `npm run lint` 경고 0개

## 다 됐다는 기준
- [ ] `npm test`에서 `[A]` 테스트가 건너뛰지 않고 모두 통과
- [ ] 계좌·카드 추가, 목록, 수정, 삭제가 화면에서 됨
- [ ] 월 예산, 고정비를 저장하고 새로고침해도 남아 있음
- [ ] 이름 없이 추가하면 오류 메시지가 보임
- [ ] 다른 아이디로 로그인하면 내 계좌가 안 보임
- [ ] 폰 크기 화면에서도 깨지지 않음

## 화면 구성 (만든 것)
위에서부터 **내 정보 → 한 달 예산 → 고정비 → 다음 달 고정지출 예상 → 알림 → 자산(은행·페이머니·카드) → 계정(로그아웃·탈퇴) → 디자인 시안(회의용)** 순서예요.
디자인은 `public/css/settings.css`(이 화면 전용, 토스·카카오페이·뱅크샐러드·노션 참고)에 있어요.
- 자주 바꾸는 예산을 맨 위에, 한 번 정하면 잘 안 바꾸는 계좌와 계정을 아래에 뒀어요.
- 추가·수정은 아래에서 올라오는 시트에서 하고, 누르는 즉시 저장돼요. (페이지 아래 "저장" 버튼 없음)
- 지우기는 두 번 눌러야 돼요. 금액 칸은 숫자만 받고 쉼표를 찍어 보여 줘요.
- **고정비**: 카테고리별로 묶고, 이름에 맞는 한 톤 선 아이콘(AI는 반짝이, 유튜브는 재생, 통신비는 휴대폰…)을 테마 색으로 붙여요. 결제일이 가까운 구독엔 "2일 뒤 결제"를 보여 줘요.
- **알림**: 구독 결제 1·3·7일 전 "계속 쓸까요?" 알림을 켜고 꺼요. 실제 알림은 아직 없고 미리보기만 있어요. (홈 화면에서 쓰면 돼요)
- **자산**: **은행(저축은행 포함) / 페이머니 / 카드**로 묶어 보여요. 공식 앱 아이콘(`public/img/banks`), 직접 적은 잔액과 어제보다 늘거나 준 금액, 이자율(은행만), 숨기기.
  - 은행·페이·카드사와 용도는 버튼으로 고르고, 없으면 "+ 직접 입력"으로 바로 추가해요. 한 번 쓴 건 다음부터 버튼으로 나와요.
  - 직접 입력한 이름도 알아봐서 아이콘으로 바꿔요. (예: "BNK부산은행", "우리동네 신협", "미래에셋증권") 모르는 이름은 테마 색 배지예요. 규칙은 `settings.js`의 `INSTITUTIONS`
  - 번호는 끝 4자리만 저장해요. 전체 번호를 붙여 넣거나 다 치고 나면 4자리로 바뀌면서 "개인정보를 보호해요" 안내가 떠요.
- **계정 → 탈퇴하기**: 지워질 기록 수(거래·자산·고정비·분류 규칙·아이디)를 먼저 보여 주고, 확인 칸과 비밀번호를 받은 뒤 서버에서 모두 지워요. (`DELETE /api/settings/membership`, `src/services/membership.js`)
  - 지운 뒤에는 이 기기에 남은 로그인 토큰·시안 설정도 지우고 "탈퇴했어요"와 지운 기록을 보여 줘요. 닫으면 로그인 화면으로 가요.
  - `user` 칸이 있는 모델을 모두 찾아 지워서, 팀원이 새 모델을 만들어도 빠뜨리지 않아요.
  - 연습 계정(demo)은 여러 사람이 같이 써서 탈퇴를 막아 뒀어요. 시험은 새로 가입한 계정으로 해요.

### 다음 달 고정지출 예상 (`GET /api/settings/suggestions`)
지난 2달 거래를 **카테고리별로** 모아 "교통 약 13만 원, 구독 약 5.7만 원"처럼 예상해요. 계산 규칙은 `docs/API.md`, 코드는 `src/services/budgetSuggest.js`.
- 카테고리 금액 = 매달 같은 금액으로 나간 돈(정기권, 구독료) + 그 밖에 매달 비슷하게 쓴 돈(버스·택시 등 "그 외")
- [추가]를 누르면 정기 결제는 그 이름 그대로, "그 외"는 **카테고리 전체 고정비**(`wholeCategory`, 예: "그 외 교통비")로 들어가요. 그래서 하루 예산에서 두 번 빠지지 않아요.
- 넣은 카테고리는 "✓ 추가됨"과 [빼기]로 바뀌어서 바로 다시 뺄 수 있어요. 넣기·빼기 뒤 알림의 "되돌리기"로 바로 전 상태로 돌아가요.
